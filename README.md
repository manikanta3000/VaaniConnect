# 🗣️ VaaniConnect

**VaaniConnect** is a multilingual conversational AI platform designed to bridge communication gaps across South Indian languages. It empowers rural communities through real-time voice translation in **Telugu, Tamil, Kannada, Malayalam, Hindi, and English**.

---

## 🌟 Features

- 🎤 Voice-to-Text Recognition  
- 🔊 Text-to-Speech Output  
- 🔄 Real-Time Language Translation  
- 🌐 Supports 6+ Indian Languages  
- 🧑‍⚕️ 🏫 🏛️ Useful in healthcare, education & governance

---

## 🖥️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python + Flask  
- **Translation**: Google Translate API (free endpoint)  
- **Voice Recognition**: Web Speech API  
- **Deployment**: Render (Free Hosting)

## 🚀 How to Run This Project Locally

```bash
# 1. Clone the repository
git clone https://github.com/manikanta3000/VaaniConnect.git
cd VaaniConnect

# 2. Create a virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install the dependencies
pip install -r requirements.txt

# 4. Run the Flask app
flask run

# The app will start at:
http://localhost:5000
